# 鱼鱼找鸡

给一张图，反查「这人是谁、账号在哪」或「这图出自哪部作品」。

## 用法

```bash
node bin/fish.mjs <图片路径或URL> [--json]
```

常用参数：

- `--engines lens,saucenao,tracemoe` —— 指定引擎（默认这三个）
- `--json` —— 只输出结构化结果，方便自己接脚本
- `--no-strict` —— 名字对不上也报（自己挑，别直接下结论）

## 引擎分工

| 引擎 | 擅长 |
|---|---|
| `lens`（谷歌 Lens） | 真人 coser；能一路追到推特主页，最准，需外网 |
| `saucenao` | 动漫 / 同人画作、画师 |
| `tracemoe` | 动漫截图反查具体集数 |
| `iqdb` | 动漫图库比对 |
| `yandex` | 通用识图，走浏览器 |

## 注意事项

- 相似度低于 0.75 不要当作「找到了」，如实说「没认出来」。
- 图片会被上传到相应引擎站点（SauceNAO / Lens 等），这是反查的必要条件；提醒用户别拿敏感图去查。
- 容器 / 服务器内的无头浏览器可能触发 Google captcha；这种情况用 `remote/lens-via-pc.mjs` 借一台局域网 PC 的浏览器跑 Lens。
- 结果里平台、账号、相似度都要如实转述，不要补细节。
